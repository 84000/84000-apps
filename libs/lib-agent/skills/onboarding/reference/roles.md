# How each 84000 role uses the plugins

Read this only when the user asks what a plugin is for in their work. Which
plugins suit which role comes from `plugins.md`, not from here.

- **Translator:** researches a text and drafts translations through the
  Stage 0 to Stage 2 workflows in 84000 Translator Tools, saving each stage's
  documents to the studio.
- **Editor:** reviews and copyedits translations with 84000 Translator Tools. If
  they are a digital editor, they also bring finished translations into studio
  with 84000 Digital Editor Tools (docx import, folio markers).
- **Manager:** follows projects in the studio and reads the translation
  policies. 84000 Core covers feedback; the research tools in 84000 Translator
  Tools are useful if they review texts themselves.
- **Admin:** everything above, plus maintaining the translation policies with
  84000 Admin.
- **Scholar or reader:** Should not have access to the plugins, but if they do,
  they can read the translation policies and research texts with 84000 Translator
  Tools.

A user whose permissions were granted individually may suit a plugin their
role alone would not; `plugins.md` accounts for that through permissions.
