# Rendering terms

## Principles

Translate for a *general reader* first, and keep **technical terms** in the
glossary. See the [style guide](https://84000.co/guidelines "Guidelines") and
the `glossary` tool.

> Where a term has no settled English, say so in a note
> rather than coining one.

### Lists

- Sanskrit in full diacritics
- Tibetan in Extended Wylie
  - Proper names capitalised
  - Common nouns lower case
- Chinese in pinyin

1. Check the glossary.
2. Check the canonical section.
3. Ask an editor.

| Term       | Rendering         |
| ---------- | ----------------- |
| bodhicitta | mind of awakening |
| karman     | action            |

Tibetan & Sanskrit names follow the same rule, with ***strong emphasis***
used sparingly.
